Mentions légales et confidentialité

Dernière mise à jour : 26 octobre 2026

Qui gère le site

Ce site est géré par Pierpalmiro Stroppa, Suisse, sous le label Intrecci di Carta. Pour toute question : info@intreccidicarta.com.

Quelles données le site collecte

Le site n'utilise pas de cookies, n'a pas de formulaires à remplir, ne mesure pas les visites et n'affiche pas de publicité.

Les polices de caractères et les images se trouvent sur le site lui-même : aucune donnée n'est transmise à Google Fonts ni à d'autres services externes.

Votre navigateur mémorise la langue que vous avez choisie dans un espace interne de votre appareil (localStorage). Cette donnée n'est envoyée à personne et vous pouvez l'effacer dans les paramètres de votre navigateur.

Où le site est hébergé

Le site est hébergé par GitHub Pages, un service de GitHub Inc. (États-Unis). Comme tout serveur, GitHub enregistre l'adresse IP des personnes qui visitent les pages, pour des raisons techniques et de sécurité, conformément à sa propre déclaration de confidentialité : GitHub Privacy Statement.

Si vous nous écrivez

Si vous nous envoyez un e-mail, nous utilisons votre adresse et votre message uniquement pour vous répondre. Nous ne les transmettons à personne.

Liens vers d'autres sites

Les liens vers Google Play et vers d'autres sites mènent hors d'ici : ce sont alors les règles et les politiques de confidentialité de ces sites qui s'appliquent.

Vos droits

En vertu de la loi fédérale sur la protection des données (LPD) et, si vous vivez dans l'Union européenne, du Règlement général sur la protection des données (RGPD), vous pouvez demander quelles données nous détenons sur vous, les faire corriger ou les faire effacer. Écrivez à info@intreccidicarta.com.

Droits d'auteur

Textes, couvertures, images et marque : © Pierpalmiro Stroppa. Toute copie ou reproduction sans autorisation écrite est interdite.

Confidentialité des jeux

Cette page concerne uniquement le site. Chaque jeu a sa propre politique de confidentialité, car il utilise la publicité de Google AdMob et les achats de Google Play : vous la trouverez sur la page de chaque jeu.
